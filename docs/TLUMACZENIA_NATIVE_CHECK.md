# Kontrola tlumaczen az / fil / id / ne

Status techniczny:
- Hydra ma komplet wersji jezykowych dla intro i interfejsu;
- istnieja pliki audio dla: `pl`, `en`, `ua`, `ru`, `az`, `es`, `fil`, `id`, `ne`;
- sprawdzono brak uszkodzonych znakow w renderze.

Do szybkiej kontroli przez native speakera:
- `az` - czy tekst intro brzmi naturalnie po azersku;
- `fil` - czy tekst intro jest prosty dla pracownika z Filipin;
- `id` - czy tekst intro jest jasny dla pracownika z Indonezji;
- `ne` - czy tekst intro jest zrozumialy dla pracownika z Nepalu.

Najwazniejsze ekrany do kontroli:
- okno wyboru jezyka;
- tekst intro;
- kafelka Przyjazd do pracy;
- kafelki lokalizacji.

Zasada kontroli:
Tekst ma szybko wyjasnic, co czlowiek moze zrobic w aplikacji. Nie dodajemy dlugich opisow.
